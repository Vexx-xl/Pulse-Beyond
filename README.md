# Pulse Beyond

Pulse Beyond is a tablet-first prototype for astronaut health reporting and crew handoff. It lets crewmembers record concerns in their own words, log available measurements, and prepare a handoff that preserves missing or uncertain information.

- [Open the live app](https://vexx-xl.github.io/Pulse-Beyond/)
- [Demo records and test evidence](https://vexx-xl.github.io/Pulse-Beyond/demo/)
- [Seven-slide presentation](Pulse-Beyond%20Presentation.pdf)
- [App source and development notes](artifacts/crewcheck/README.md)

The app uses fictional crew profiles for demonstrations and stores records in the current browser.

## Publish on GitHub Pages

In the repository, open **Settings → Pages** and set the publishing source to **GitHub Actions**. Run **Deploy Pulse Beyond to GitHub Pages** from the **Actions** tab, or push to `main` to trigger the build. The workflow builds the crew app and publishes the presentation alongside it.
