# NASA ISS visual reference

Model: International Space Station (ISS) (A)
Source and contributor: NASA/Ames Research Center
Source page: https://science.nasa.gov/3d-resources/international-space-station-iss-a/
Library: https://science.nasa.gov/3d-resources/
Usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/

The original 39,708-byte GLB is included unchanged. The preview is NASA's own
model preview, resized by NASA's image service to 960 × 540. No medical or
operational information has been inferred from these files. NASA does not
endorse Pulse Beyond. This model is an illustrative exterior reference, not a
current verified mission configuration, interior map or live data feed.
